# Visual Markdown Editor 기본 문서

이 문서는 제목과 일반 문단의 기본 round-trip 동작을 확인하기 위한 fixture입니다.

## 한글과 영어 문단

한글 문장과 English words가 한 문단 안에서 자연스럽게 함께 표시됩니다.

두 번째 문단은 빈 줄로 구분되며, 문단 경계가 저장 후에도 유지되어야 합니다.

## Unicode 문자

이모지 🚀 ✨, 통화 기호 ₩ € ¥, 화살표 → ←, 수학 기호 ± × ÷를 그대로 보존합니다.
